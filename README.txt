GPIO example

    MCU中的IO口主要有输入跟输出两种工作模式。在初始化IO口时，可选择IO口的
组别、工作模式和端口号。通过gpio_bit_set和gpio_bit_reset可控制IO口输出高
低电平及电平翻转。IO口的中断有高电平、低电平、上升沿和下降沿四种触发方式。IO
口设置为输入模式后，当接收到外部来的一个信号并触发中断，将进入对应端口的中
断服务函数，可用于实现指定信号状态下需执行的某些操作。本GPIO工程实现的是在
IO口中断中开启LED灯。

    配置如下：
    PA5 ———— 设置为输入、上拉电阻使能、使能中断、下降沿触发中断
    PA2 ———— 设置为输出
    PD2 ———— 设置为输出

    使用：
    在硬件电路上PA2连接PA5，当PA2进行电平翻转时，会改变PA5输入电平状态，
触发外部中断，进入GPIO中断服务函数，在中断服务函数中对PD2进行翻转。
